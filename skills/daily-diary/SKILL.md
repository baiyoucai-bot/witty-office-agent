# 每日日记

日记按日放在用户记忆 `diary/YYYY-MM-DD.md`，带日期的句子同时进时间线。
工具：`diary_write` / `diary_read` / `diary_list`。

一份日记分三节：

| 小节 | 谁写的 | 内容 |
|------|--------|------|
| `## 小结` | 自动，攒够条目或跨日时后台生成 | 这一天的归纳 |
| `## 我做了什么` | 自动，每轮末尾本地抽 | 助手调过的工具、动过的文件 |
| `## 你说了什么` | `diary_write` 或线索词收割 | 用户自述的行程 |

## 何时用

- 用户说「今天下午开了验收会」「刚才把周报发出去了」。
- 用户问「我今天干了啥」「这周时间线」。

## 做法

1. 用户自述的当天行为用 `diary_write`，不要只记在对话里。
2. **不要**用 `diary_write` 复述自己调工具的过程——「我做了什么」那一节是自动写的，手工再记一遍就是重复。
3. 回顾先看系统提示里的「今天的日记」，不够再 `diary_read`（可带 `YYYY-MM-DD`）或看时间线格子 `timeline`。
4. 不要编造没说过的行程。没有日记就说还没有。
5. 链接和邮件动作也可以记一行，方便以后对照。
