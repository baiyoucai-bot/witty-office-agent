# 链接库

业务技能，不是内核循环。条目落在 `agent_state/links/links.jsonl`，和九宫格分开。

工具：

- `link_ingest` 从聊天原文抽 URL，并尽量记下称呼和意图
- `link_add` 补标题、意图、别名
- `link_search` 按关键词查；空查询按习惯列出
- `link_resolve` 把「OA」「周报那个网」对到已入库地址，并记一次使用
- `link_habits` 看最常用的系统和意图履历

## 路由

1. 见到网址先入库。聊天里的 URL 会自动收割；`web_fetch` 打开过的也会记。
2. 含糊指代先 `link_resolve`，不要猜公网域名。
3. 同一地址只增加 hits，新意图追加履历。
4. 「又称 / 也叫 / 就是 / 简称」会收成别名。

## 纪律

- 不要把公网短链当成内网系统。
- 不要把链接抄进 prefs。
- 没有命中就说链接库没有，让用户给完整地址。
