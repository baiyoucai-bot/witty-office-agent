# 分析深度阶梯

**先判级，再动手。** 判不准往低一级走——多给的分析是噪声，少给的是偷工，但硬凑的分析比不给更糟。

## 判据

按问句的**输出形态**判，不是按问句长度或语气。

| 级 | 触发特征 | 典型问法 |
|----|----------|----------|
| L0 | 要行级记录，无聚合 | 「把 X 的清单列出来」「查一下 Y 的明细」 |
| L1 | 一个聚合值，无分组 | 「一共多少」「平均是多少」 |
| L2 | 一个分组维度 | 「各 X 的 Y」「哪个最高」「占比多少」 |
| L3 | 有时间维度 | 「趋势」「按月」「同比」「这几年」 |
| L4 | 问原因/异常/未来 | 「为什么涨了」「有没有异常」「会到多少」 |

**升级规则**：同时命中多条按最高的走。「各区近半年趋势」= L3（分组 + 时间）。「各区为什么差这么多」= L4。

**降级规则**：判不准、数据不够、时间跨度不足两期，明说降级理由再按低一级交付。

## 各级必须交付

### L0 查明细
- 表格。行数超 50 时说明总数并给出筛选条件。
- **不出图，不算平均，不写「可以看出」**。用户要的是记录本身。

### L1 单指标
- 数字 + 单位 + 时间范围 + 口径一句话。
- 口径要说清：算的是哪些行、排除了什么。「本月用电量 1240 万 kWh（含全部 220kV 站，不含试运行）」。
- 不出图。一个数画不出信息。

### L2 对比/构成/排名
- 图：对比用 column/bar，占比用 pie（类别 ≤6），排名用横向 bar。
- **差距要点名**：最高、最低、极差或倍数。「城东变 156MW，是最低的开发区变的 2.6 倍」。
- 占比类要给出头部集中度：前 N 个占多少。
- 不要只说「存在差异」——那是废话，给数。

### L3 趋势/时序
- 折线图。多序列 ≤5 条，超了先聚合再画。
- **环比**（对上一期）和**同比**（对去年同期）至少给一个；两期都不够就说明「只有 N 期数据，不足以判趋势」。
- **波动要判性质**：算历史均值和标准差，落在 ±1.5σ 内的先当噪声，别报成「显著上升」。
- 拐点、断档、异常单点要点出来，不要让折线自己说话。

### L4 归因/异常/预测
- **多图**：总量趋势 + 至少一个维度拆解。
- **拆解要落到贡献度**：哪个维度/成员贡献了多少变化量。「总量增 8%，其中江北新区贡献 5.2 个百分点」。
- **给区间不给点值**。预测尤其如此：说范围、说依据期数、说不确定来源。
- 守 `data-analysis` 的四条红线：
  - 相关不写成因果。数据里看到同步变化，写「同步变化」，不写「导致」。
  - 点估计不算结论，带波动范围。
  - 显著不等于重要，给效应量和业务含义。
  - 变化先和自身波动比，±1.5σ 内当噪声。
- 数据支撑不到归因（只有一个维度、期数太少、缺对照）时**明确说做不了**，降到 L3 交付，不要用相关性凑一个因果故事。

## 反例

- 用户问「列出所有 220kV 变电站」，交付里附了个饼图 → L0 出图，噪声。
- 用户问「各区近三年负荷趋势」，只给了一张表 → L3 缺图缺同比，偷工。
- 用户问「为什么城东变负荷涨了」，回「因为用电需求增加」 → 循环论证，没有数据支撑的归因。
- 用户问「下个月会到多少」，回「预计 168.5MW」 → 点估计当结论，且没说依据。
