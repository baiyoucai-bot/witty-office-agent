# 图表类型决策

**按数据形状选，不按好看程度选。** 默认柱状图是偷懒。

## 决策流程

照顺序问，第一个命中的就是答案：

1. **要看行级记录？** → `table`。明细不画图。
2. **只有一个数？** → 不出图。写在正文里。
3. **有时间维度？** → `line`。时间必须放 X 轴且按时序排。
4. **要看占比且类别 ≤6？** → `pie`。
5. **类别多（>8）或名字长？** → `bar`（横向）。名字不会挤成一团。
6. **其余的分类对比** → `column`（纵向）。

## 各类型的硬条件

### line 折线
- X 轴必须是时间且**已按时序排**。SQL 里没 ORDER BY 时间，折线就是错的。
- 序列 ≤5 条。超了先按维度聚合，或者拆成小多图。
- 时间点 ≥3 个。两个点是线段，不是趋势。
- 有断档（某月无数据）要么补零要么断开，不要让折线直接跨过去——那是假装连续。

### column 纵向柱
- 类别 ≤8 个。
- 名字超过 6 个字考虑换 bar。
- Y 轴**从 0 开始**。截断轴会把 3% 的差异画成一倍差，是误导。

### bar 横向柱
- 类别多、名字长、或要做排名时用。
- 排名必须排序：从大到小，最长的在上。
- 同样从 0 开始。

### pie 饼图
- 类别 **≤6**，且各项加起来是**同一个整体的 100%**。
- 类别多了合成「其他」，但「其他」不能是最大的那块——那说明分类粒度选错了。
- 不是构成关系（比如各区的平均值）**不能用饼图**，平均值加起来没有意义。

### table 表格
- 明细、多指标并列、或类别太多画不动时用。
- 行数超 50 只显示前 50 并说明总行数。

## 多指标怎么办

- **量纲相同**（都是 MW）→ 一张图多序列。
- **量纲不同**（MW 和 次数）→ 拆成两张图。不要用双 Y 轴，两个轴的刻度可以任意缩放，等于可以画出任何想要的相关性。
- **既有分组又有多指标** → 一个指标一张图，标题写清是哪个指标。

## 出图命令

```bash
<沙箱 Python> <技能目录>/scripts/plot_result.py --input <结果.csv> --chart <line|bar|column|pie> --out <图.png>
```

默认第一列当 X/类别，其余数值列当序列。要指定就用 `--x <列名> --y <列名,列名>`。

脚本会自己拦这几种错：pie 类别超 6、line 的 X 轴不像时间、没有数值列。被拦了改图表类型，不要加参数硬绕。

## 中文字体

脚本按顺序试 PingFang / Heiti / Songti / Noto / WenQuanYi，都没有就退回英文标签并在图上标注，不会画出一堆方块。真要中文标签就在系统里装一个中文字体。
