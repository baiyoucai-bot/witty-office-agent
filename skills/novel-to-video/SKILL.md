# 小说转即梦视频

小说进，**素材台账 + 角色关系 + 逐帧文案 + 视频描述词**出。产物直接对着即梦网页版的四栏填：文案、人物/场景/物品、模型参数、视频描述词。

本技能只写文字。生图、出片、下载由用户在即梦里做，或另接生成工具。

## 何时用

用户有一段小说、大纲、故事或剧本，要变成 AI 视频。只想润色单条提示词的不用建工程，直接看 `references/seedance-prompt.md` 改。

## 硬规矩

1. **@引用必须落到台账**。`@赵倩` 在 `人物.md` 里没有同名素材，即梦就吃不到参考图，只会现编一个人。名字逐字一致，不许简称。
2. **素材名不跨槽位**。一个名字只能是人物、场景、物品中的一个。
3. **台词按秒算字**。中文约 4.5 字/秒。9 秒最多 40 字，含标点。超了就是念不完被截断。
4. **一帧一个动作单元**。镜头切换单帧不超过 3 次。讲不完拆帧，不要压时间轴。
5. **不加文字元素**。无字幕、无文字叠加、无水印、无 logo、无 BGM。这条写进项目卡的全局执行规则，每帧都要带。
6. **时间轴不留空白**。`[0-5.8秒]` 接 `[5.8-9秒]`，中间断开的那一段模型会自己编。

## 五步

### 1 起工程

```bash
<沙箱 Python> <技能目录>/scripts/init_project.py --name <项目名> --root <放哪里> --duration 9 --ratio 16:9
```

建出 `项目卡.md`（出片参数 + 全局规则，全工程唯一真相）、三份素材台账、`关系.md`、`分镜.md`、`提示词/`、`参考图/`。幂等，已存在的文件不覆盖，可以随时补 `--frames N`。

比例、时长、分辨率、风格先问清楚：竖屏短剧 `9:16`，横屏 `16:9`。写进项目卡后单帧文件不要各写一套。

### 2 拆素材

通读原文，找出**会被看见**的实体，登进对应台账。判断标准只有一条：换掉它还是不是同一个？

- **身份**：换一个就不是同一个人/地/物 → 新素材
- **变体**：还是同一个，但换了衣服、受了伤、天变了、盒子拆了 → 同素材下记状态，不要新开
- **镜头瞬态**：姿势、视线、站位、机位 → 归分镜，不进台账

每个素材写**识别锚点**：可见、可生成、可比对。"气质忧郁"不是锚点，"左眉尾一道浅疤"是。锚点写法和反例见 `references/assets.md`。

素材名就是即梦里 @ 的那个词。用原文人名，别起艺名。

### 3 理关系

填 `关系.md`：谁对谁有什么诉求、对方怎么挡、**可见后果**是什么。关系不是背景资料，它直接决定站位、视线和台词落点——"递东西被无视，手停在半空"这种可见后果，就是分镜要拍的东西。

顺手画 mermaid 关系图，人物超过 5 个时必画。信息差单列一节：谁知道什么，这一集会打破哪条关系。

### 4 写帧

一帧一个 `提示词/FRAME-00X.md`，同时在 `分镜.md` 登一行。每帧四段：

- **出镜**：这一帧要挂哪些人物/场景/物品参考图。描述词里 @ 到的，这里必须列。
- **文案**：`【场景：…】` + `[首帧画面]` + `[尾帧画面]`。首尾帧写**状态**不写过程——首帧是起点画风，尾帧是终点画风，中间交给模型。
- **视频描述词**：按时间轴分段，每段写运镜 + 主体动作表情 + 空间位置 + 音频四维。台词单独一行 `【@某人台词】："…"`。写法和 @引用语法见 `references/seedance-prompt.md`。
- **全局执行规则**：指回项目卡，或原样抄一份。

跨帧连续性靠台账，不靠记忆：人物换了造型、物品变了状态，先更新台账再写下一帧。

### 5 过校验

```bash
<沙箱 Python> <技能目录>/scripts/check_prompts.py --project <工程目录>
```

查 @引用能不能落到素材、台词塞不塞得进那一段秒数、时间轴有没有断口和越界、有没有偷偷加字幕 BGM、镜头切换有没有超、出镜清单和描述词对不对得上、分镜索引和帧文件对不对得齐。

**有 FAIL 就改，改完重跑**。这些全是静默失败——即梦不报错，它照着糊出来一版，积分照扣。WARN 要么改掉，要么在交付里说明为什么可接受。

## 交付

给用户：工程路径 + 帧清单 + 校验结果（FAIL 数、剩余 WARN 及原因）。每帧的**出镜清单、文案、视频描述词**三段直接可复制进即梦对应栏位。

不要替用户点生成。参考图还没出的素材，在交付里单列一张待生成清单。

## 出片顺序

先出参考图，再出视频。改一张图的成本远低于改一段视频，构图错了先改图。关键爆点帧用首尾帧锁死过渡，普通帧用首帧驱动。
