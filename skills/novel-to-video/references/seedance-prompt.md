# 即梦 Seedance 视频描述词写法

即梦网页版的「视频描述词」栏。素材挂在左边的人物/场景/物品槽位，描述词里用 `@名字` 把它们接进来。

## @引用语法

`@` 是唯一把参考图接进画面的手段。不写 @，模型就现编一个人。

| 要指定 | 写法 |
|---|---|
| 人物形象 | `@赵倩` 直接出现在动作句里 |
| 场景/背景 | `场景参考 @教学楼空地` |
| 首帧 | `@图片1 作为首帧` |
| 尾帧 | `@图片2 作为尾帧` |
| 服装 | `穿着 @校服 的服装` |
| 运镜 | `参考 @视频1 的运镜效果` |
| 动作编排 | `参考 @视频1 的动作编排` |
| 特效转场 | `完全参考 @视频1 的特效和转场` |
| 音色语气 | `旁白音色参考 @视频1` |
| 音效 | `音效参考 @视频3 的音效` |
| 台词归属 | `【@赵倩台词】："…"` |

网页版按槽位挂图时，@名字就是台账里的素材名。用 API 或多图输入时是 `@图片1` `@视频1` 这种序号引用——两种不要混着写在一句里。

## 结构

```
[出镜角色-物品-场景]:
人物: @陈浩, @赵倩, @林小雅
场景: @校园空地
角色-声线绑定: @陈浩 | 少年音偏清亮 |

[0-5.8秒]: 白天，@校园空地 中景拍摄。@陈浩 宿醉未醒，皱眉按着太阳穴；@赵倩 站在他正前方嚷道，@林小雅 站在一侧低头不语。
【@赵倩台词】："陈浩，你是不是聋了，怎么不说话？"

[5.8-9秒]: 镜头切至 @陈浩 近景并缓慢推近。@陈浩 耳边嗡鸣，神色骤然消暗，下意识摸向口袋却摸空，手停在口袋边。

全局执行规则:
动漫风格，高质量。
基础硬性要求：画面全程无任何字幕、无文字叠加、无水印、无 logo、无额外文字标识；无背景音乐、无 BGM、无配乐；只保留纯画面、剧情人声与环境/动作音效，拒绝一切文字元素。
```

## 每段四维

一段时间轴里按顺序写这四样，缺一样模型就自己补：

1. **运镜或镜头切换**：`中景拍摄` / `固定机位` / `镜头切至…近景并缓慢推近` / `全景缓慢推近`
2. **主体动作与表情**：核心角色的关键动作、神态变化。动作要能演——"神色骤然消暗"能演，"内心五味杂陈"不能。
3. **位置或空间变化**：谁在谁的哪一侧、朝向、进出画。站位来自角色关系，不是随手放。
4. **音频**：环境音、动作音效、人声。台词单独起一行标明说话人。

## 时间轴

- 分段起止要接上：`[0-5.8秒]` 接 `[5.8-9秒]`。中间空一段，模型自己编那一段。
- 段数控制在 2-3 段。9 秒切三次以上会糊。
- 不要给每个小动作都标秒。标到能卡住节奏就够。

## 台词预算

中文约 **4.5 字/秒**，含标点。

| 段长 | 台词上限 |
|---|---|
| 3s | 13 字 |
| 5s | 22 字 |
| 5.8s | 26 字 |
| 9s | 40 字 |

超了不会报错，会被截断或抢拍。台词长的先拆帧。

## 常踩的坑

| 症状 | 原因 | 改法 |
|---|---|---|
| 人物长得不像参考图 | 描述词里没 @ 到，或名字写错一个字 | 名字逐字对台账 |
| 参考图挂了但没生效 | 素材没进出镜清单 | 出镜清单和 @引用对齐 |
| 画面冒出字幕/花字 | 没写死无文字要求 | 全局执行规则每帧都带 |
| 台词念不完就切 | 字数超过段长预算 | 按 4.5 字/秒砍，或拆帧 |
| 动作糊成一团 | 一帧塞了太多动作单元 | 一帧一个动作单元 |
| 中间凭空多出一段戏 | 时间轴有空白 | 分段首尾相接 |
| 前后帧不像一个人 | 台账没更新，锚点靠记忆 | 变体状态写回台账 |
| 运镜抢戏 | 复杂运镜没有叙事理由 | 复杂运镜只在需要揭示信息时用 |

## 首尾帧

- **首帧**：这一帧的起点状态。写画面，不写过程。
- **尾帧**：终点状态。和首帧之间必须有可见变化——位置、姿态、表情、光线至少变一样。
- 关键爆点帧用首尾帧双锁，模型只负责插值，过渡不会跑偏。
- 普通帧只给首帧，动作交给描述词，成本更低。
