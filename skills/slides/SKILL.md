# Slides

做汇报/评审用的 **HTML 或 Markdown** 草稿，路径由用户指定。

用户要 **可编辑 .pptx / PowerPoint** 时切到 `ppt-master`，不要在这里手写 Office 文件。

## 开始前

确认主题、听众、页数上限、是否已有素材。没有主题不要动手。

## 结构

1. 封面：标题、场合、日期。
2. 每页一个观点。数字用对比，流程用步骤，不要整页段落。
3. 结尾：结论和下一步。备注可写在 HTML 注释或 Markdown 引用里。

## 约束

- 一页不超过 7 条要点。
- 不要编造未提供的业绩或制度。
- 改已有文件时只动内容，保持原版式约定。

写完打开文件核对页数、标题和数字，然后停止。
